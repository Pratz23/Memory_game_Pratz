# Project Context

## What this repo does
This repository contains a simple browser-based Memory Game built with plain HTML, CSS, and JavaScript.

The app lets a player:
- flip cards to find matching pairs
- play on either a 4x4 or 6x6 grid
- track moves and elapsed time
- get a star rating based on performance
- save best scores in browser local storage
- play using mouse or keyboard
- reset and replay the game after completion

It is a lightweight front-end project with no external dependencies and runs directly in a browser.

## What the project is
The main file is:
- memory-game.html

This file contains:
- the game layout and styling
- the card grid logic
- timer and score tracking
- win detection and modal popup
- local storage handling for high scores

## What the repo name stands for
The repository name is `memory-game-GHCP`.

In this context, `GHCP` most likely refers to GitHub Copilot, which is a common naming convention for projects created or enhanced with GitHub Copilot assistance. The app itself is still just a memory matching game and does not use any backend or service tied to GitHub Copilot.

## Summary
This repo is a small interactive web game meant to practice front-end logic, UI design, accessibility, and browser-based state management. It is a classic memory matching game with a polished user experience and no framework overhead.
